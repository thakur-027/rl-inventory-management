How This Works

🎯 The Problem

Balance inventory under 3-day lead times to minimize holding (₹2.5/day), stockout (₹100/unit), and order costs (₹50) while fulfilling demand.

🧠 The Solution

Pipeline-aware DQN agent observes on-hand stock and orders in transit, learning optimal replenishment quantities.

📊 Scientific Validation

Compared against (s, S) grid-search, EOQ, and Fixed Reorder using Common Random Numbers with paired t-tests.

Environment Setup

Holding Cost: ₹2.50 per unit/day (end-of-day)
Stockout Cost: ₹100 per unmet unit

Agent Configuration
